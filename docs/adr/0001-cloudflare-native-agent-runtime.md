# Cloudflare-Native Agent Runtime

Better Agent will target a Cloudflare-native runtime where Durable Objects, Cloudflare Agents, and Project Think own durable agent state, streaming sessions, tool use, approvals, and recovery. The Coordinator runtime is one per user/account and stays thin. The primary work runtime identity is one Thinkspace Agent runtime per Thinkspace; conversations and sessions are interaction surfaces within that Thinkspace, not separate owners of durable agent state. Product APIs act as the control plane for account, auth, indexing, and configuration, while Thinkspace Agent runtimes own the agent loop, messages, tool runs, approvals, and memory changes. We are choosing this over a request-scoped chat API, local-first runtime, or runtime-agnostic service layer because the product center of gravity is durable web-native Thinkspaces, not ephemeral chat turns or broad local-machine automation.

Considered alternatives: keeping the current request-owned chat turn model; building a portable backend first; making local nodes the primary runtime. The consequence is intentional Cloudflare platform coupling in exchange for colocated durable agent state, web-first deployment, and a runtime shape aligned with scoped Thinkspace Agents.
