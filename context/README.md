# Better Agent Context

Better Agent is the proposed evolution of Better Chat: not a more powerful chatbot, but a web-first coordinator for creating focused, scoped, durable AI agents.

The central idea:

> Better Agent helps humans create **Thinkspaces**: bounded project environments with their own purpose, memory, tools, sources, permissions, and dedicated Thinkspace agent.

Better Agent is explicitly **not** a universal “do anything” assistant. It is not Jarvis. It is not a single persistent AI personality with a soul. It does not attempt to remember everything about the user or act everywhere on their behalf.

Instead, Better Agent is an orchestrator that helps users stand up focused, purpose-built agents for specific projects, questions, investigations, monitoring tasks, research efforts, plans, and adjacent-to-coding work.
