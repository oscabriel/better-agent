# Sittings as the Primary Judgement Surface

Better Agent will treat the **Sitting** — a deliberate, live, streamed working session between the user and one Thinkspace Agent — as the primary surface where the user's judgement is applied, with the cross-Thinkspace Review Queue demoted to a ripeness signal ("which Thinkspace is worth my next Sitting") rather than the place judgement happens. A Thinkspace's rhythm is: defer (the agent produces durably while the user is away, via submissions and Routines), sit (the user returns, holds their Attention on that one Thinkspace, reads deeply, converses live, iterates and discards), and export (the molded findings leave the app as an Artifact bound for its proper destination — a repo, notes app, spreadsheet, or deck). We are choosing this over the earlier "Review Queue as primary surface, browser streaming last" framing because that framing produced a merge-queue dashboard, and the product intent is deep thinking work: ADR-0005's attention architecture rejects *concurrent* interactivity — twenty live streams competing for one serial mind — not interactivity itself.

Considered alternatives: keeping all interaction batch-shaped (submit/inspect only), which makes iteration and real conclusions impossible; treating live chat as a late enhancement (`live_surfaces_v5`), which defers the product's core loop indefinitely; processing agent output purely through queue items, which spends Attention on triage instead of thinking. The consequence is that authenticated per-Thinkspace session access (auth-before-router in the worker, fail-closed 404 preserved for everything else) moves forward in the unlock sequence as its own vertical slice, while the governance invariants are unchanged: every Sitting turn flows through the same per-turn resolution and Permission gates as away work (ADR-0004, ADR-0007), external mutations still hold for Approval (ADR-0003) — granted live during a Sitting or parked until the next one — and Backpressure (ADR-0005) paces what accumulates *between* Sittings. This reinforces ADR-0006: Project Think's interactive face (WebSocket chat, stream resumption, recovery indicators) serves the Sitting, and its durable face (submissions, scheduling) serves the gaps, on the same Durable Object.
