# Versioned Agent Profile Activation

Better Agent will treat changes to an Agent Profile as explicit revisions that take effect only when the user activates them, rather than editing the live configuration in place. A revision being shaped with the Curator — during Thinkspace creation or later reconfiguration — is a resumable draft until activated. Each activation is recorded in the Audit Trail, and every Thinkspace Agent turn remains attributable to the exact Profile revision it ran under.

We are choosing this over mutable edit-in-place because Thinkspace Agents take scheduled, proactive, and externally visible actions, and the user must be able to answer "what instructions, model behavior, and tool references was the agent running when it did that?" Retrofitting turn-to-revision attribution after proactive turns exist would be a painful migration, while draft-until-activated also preserves judgement the user has already spent (interrupted Curator sessions resume instead of restarting) and gives the runtime one unambiguous trigger for reconciling derived state such as scheduled prompts. The consequence is more lifecycle machinery — draft, active, and superseded revisions instead of one mutable row — and an extra activation step for trivial edits, in exchange for reproducible turn behavior, a trustworthy Audit Trail, and Review Queue-compatible draft semantics.
